# Data Science Final Projects - Internship Evaluation

This repository contains the complete technical implementation and deliverables for the final evaluation projects as part of the Data Science Internship program.

## 📁 Repository Structure & Projects

* **DS-03.ipynb (Large-Scale Social Media Intelligence Platform)**
  * **Objective:** Collects social media posts, performs sentiment analysis, implements misinformation/fake-news detection heuristics, and builds NetworkX-based influencer graph rankings (PageRank).
  * **Key Techniques:** Text preprocessing, TF-IDF vectorization, LDA topic modeling, and graph analytics.

* **DS-81.ipynb (Customer Lifetime Value and Churn Intelligence System)**
  * **Objective:** Predicts customer churn probabilities, estimates Customer Lifetime Value (CLV), and provides an automated retention offer recommendation engine.
  * **Key Techniques:** Exploratory Data Analysis, feature engineering, predictive classification modeling, and business logic mapping.
